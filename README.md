# Muhammad Hammad Portfolio

## Setup
1. Place your photo at `static/hammad.jpg` (or rename in app.py if .png)
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://localhost:5000

## Deploy to Vercel
```bash
npm install -g vercel
vercel
```

## Photo Setup
- Create `static/` folder in project root
- Put your photo as `hammad.jpg` (or `hammad.png`)
- If using a different filename, search for `hammad.jpg` in app.py and replace
